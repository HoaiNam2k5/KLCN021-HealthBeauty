# HealthBeauty Mobile

Ứng dụng Flutter khách hàng, dùng chung API tại thư mục ../HealthBeauty.Api.
Yêu cầu Dart ^3.13.4; máy hiện tại dùng Flutter 3.47.7 / Dart 3.13.5.

Tại thư mục dự án chung, mở emulator và chạy `.\CHAY_FLUTTER.ps1`.
API Android emulator: http://10.0.2.2:5230/api/v1.
Xem [hướng dẫn chạy chung](../README.md), [thay đổi Flutter](REVIEWS.md) và [cấu hình Google Android](GOOGLE_LOGIN_ANDROID.md).
