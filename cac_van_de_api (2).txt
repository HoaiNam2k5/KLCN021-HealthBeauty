--Web quản trị cần mấy chỗ này ở API lịch hẹn (đã đối chiếu Swagger):
1) POST /appointments hiện không có customerId và staffId. Lễ tân cần đặt lịch hộ khách và chọn nhân viên. Nhờ thêm customerId (bắt buộc với Admin/Manager/Reception) và staffId vào CreateAppointmentRequest.
2) GET /appointments chưa có bộ lọc. Nhờ thêm query: from, to, status, staffId, keyword (tên/SĐT khách), kèm phân trang.
3) PATCH /appointments/{id}/status: nhờ mô tả danh sách trạng thái hợp lệ và luồng chuyển hợp lệ (enum trong Swagger).
4) Schema response của available-slots, GET /appointments/{id} và GET /staff/{id}/appointments chưa có trong Swagger, nhờ khai báo.
5) Catalog đang lệch code (password/account, tên trường tiếng Anh); nhờ cập nhật lại catalog.

1. MỞ QUYỀN API LẤY DANH SÁCH KỸ THUẬT VIÊN (GET /api/v1/staff)
--------------------------------------------------------------------------------
- Vị trí file: HealthBeauty.Api/Controllers/CustomersController.cs (class StaffController)
- Hiện trạng: 
    Class StaffController đang được cấu hình:

    Điều này khiến khách hàng (tài khoản role "Customer") khi vào bước đặt lịch 
    và gọi API GET /api/v1/staff sẽ bị trả về lỗi 403 Forbidden.
- Đề xuất sửa:
    Cho phép tài khoản Khách hàng (hoặc cho phép Anonymous) được gọi GET danh sách

    Gợi ý:

            { ... }

2. XỬ LÝ LỖI LOGIC: KIỂM TRA TRÙNG LỊCH THEO KHOẢNG THỜI GIAN THỰC TẾ
   (Áp dụng cho POST /api/v1/appointments và POST /api/v1/appointments/{id}/reschedule)
--------------------------------------------------------------------------------
- Vị trí file: 
    + HealthBeauty.Api/Controllers/AppointmentsController.cs (method Create)
    + HealthBeauty.Api/Controllers/SupplementControllers.cs (method Reschedule)
- Hiện trạng: 
    API hiện đang kiểm tra trùng lịch bằng so sánh bằng đúng thời điểm bắt đầu:
        x.NgayGioHen == request.AppointmentAt
    => Lỗi logic: Nếu khách hoặc nhân viên đã có lịch lúc 09:00 kéo dài 60 phút (09:00 - 10:00),
       khi khách hoặc người khác đặt lịch lúc 09:30, hệ thống vẫn cho phép đặt vì 09:00 != 09:30.
- Đề xuất sửa:
    Kiểm tra va chạm theo khoảng thời gian [Bắt đầu, Kết thúc):
    Hai khoảng thời gian [newStart, newEnd) và [existingStart, existingEnd) trùng nhau khi:
        existingStart < newEnd && newStart < existingEnd

    Gợi ý triển khai trong AppointmentsController.cs:
    ----------------------------------------------------------------------------
    var newStart = request.AppointmentAt;
    var newDuration = request.Items.Sum(item => 
        services.TryGetValue(item.ServiceId, out var s) ? s.ThoiLuongPhut : 30);
    if (newDuration <= 0) newDuration = 30;
    var newEnd = newStart.AddMinutes(newDuration);

    // Lấy các lịch hẹn trong ngày của khách hàng hoặc của nhân viên được chọn
    var existingList = await db.Lichhens
        .AsNoTracking()
        .Include(x => x.Chitietlichhens).ThenInclude(x => x.DichVu)
        .Where(x => x.TrangThai != "DaHuy" 
                 && x.NgayGioHen.Date == newStart.Date 
                 && (x.KhachHangId == customerId.Value || (request.StaffId.HasValue && x.NhanVienId == request.StaffId.Value)))
        .ToListAsync(cancellationToken);

    var conflict = existingList.Any(x =>
    {
        var existingStart = x.NgayGioHen;
        var existingDuration = x.Chitietlichhens.Sum(ct => ct.ThoiLuongThucTe ?? ct.DichVu?.ThoiLuongPhut ?? 30);
        if (existingDuration <= 0) existingDuration = 30;
        var existingEnd = existingStart.AddMinutes(existingDuration);
        
        return existingStart < newEnd && newStart < existingEnd;
    });

    if (conflict) 
        return Conflict("Khách hàng hoặc nhân viên đã có lịch hẹn trong khoảng thời gian này.");
    ----------------------------------------------------------------------------
    (Tương tự với method Reschedule trong SupplementControllers.cs)

--------------------------------------------------------------------------------
- Vị trí file:
    + HealthBeauty.Api/Contracts/AppointmentContracts.cs
    + HealthBeauty.Api/Controllers/AppointmentsController.cs (hàm Map)
- Hiện trạng:

    của từng mục dịch vụ (AppointmentItemResponse) chưa có thông tin thời lượng (phút).
- Đề xuất sửa:
    1) Trong AppointmentContracts.cs:
        public sealed record AppointmentItemResponse(
            int Id, 
            int ServiceId, 
            string ServiceName, 
            int? ComboId, 
            double ExpectedPrice,
            int DurationMinutes = 30
        );

    2) Trong AppointmentsController.cs (hàm Map):
        item.Chitietlichhens.Select(x => new AppointmentItemResponse(
            x.ChiTietLichHenId,
            x.DichVuId,
            x.DichVu?.TenDichVu ?? string.Empty,
            x.ComboId,
            x.GiaDuKien,
            x.ThoiLuongThucTe ?? x.DichVu?.ThoiLuongPhut ?? 30
        )).ToList()
